# G8.2.1 supervisory fail-closed corrections

**Date:** 2026-08-08
**Scope:** local acceptance tooling and evidence only. No product/API/pipeline/UI behavior, AWS,
Terraform, remote, release or deployment action.

G8.2.1 is a forward-only correction of six independently identified acceptance-tooling gaps. It
does not amend any accepted commit. The corrected tools were exercised against freshly rebuilt,
source-bound `linux/amd64` worker and API images before the runtime evidence below was recorded.

A final supervisory delta then closed two proof-policy edge cases without changing any production
image input: canonical lowercase `.pyc`/`.pyo` remain excluded exactly like the case-sensitive
Docker context, while unusual uppercase/mixed-case bytecode is source-bound; and canonical Docker
absence text is accepted only with exit code 1. Focused and full-worker counts below include these
regressions. Recomputed worker/API digests remained byte-for-byte equal to the image labels shown
below, so rebuilding or repeating the long runtime gates would have produced no new image evidence.
