## Claim-narrowing ladder (pre-agreed truthful fallbacks)

1. **Selected:** full gate passed → handoff §18 Milestone A claim, narrowed to
   "persisted human edits" rather than a broader review-workflow claim.
2. Historical fallback only: if G12 had not passed, the same claim would omit the
   real-provider evidence sentence and say "verified with deterministic provider".
3. Audio stack de-scoped from smoke (R1 fallback) → claim says "core scene-drafting workflow" instead of "multimodal"; audio parity moves to v0.2.
4. Cloud smoke green only locally (LocalStack) by the deadline → **no AWS claim at all**; publish "cloud-ready architecture (FastAPI/PostgreSQL/S3/SQS) with local parity" and finish the deploy before any AWS wording ships.
